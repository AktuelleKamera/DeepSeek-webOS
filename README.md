# DeepSeek for webOS

一个面向 HP TouchPad (webOS 3.0) 设备的 DeepSeek 客户端，让被遗忘在抽屉里的 webOS 设备重新获得与 AI 对话的能力。

## 当前版本

**1.0.0 (正式版)** 

---

## 已实现功能 (1.0.0)

- 支持 HP TouchPad (webOS 3.0) 设备
- 基于 Enyo 框架开发
- 黑色主题 / 粉色主题切换
- 基本的对话界面
- 发送消息和接收回复
- 对话历史记录
- 多轮对话支持
- Markdown 渲染
- 自定义 API 地址

---

## 技术路线

- 基于 Enyo 2.5.1 / webOS 3.0 原生框架
- JavaScript 实现
- 使用 XMLHttpRequest 调用 DeepSeek API
- 支持 Markdown 渲染（待实现）

---

## 兼容性说明

本项目的目标设备是 HP TouchPad (webOS 3.0)。

### 配置
- 系统: webOS 3.0
- 处理器: 1.2GHz ARMv7双核
- 物理内存: 1GB

---

## 本项目是如何出现的？

开发者做了 BiliClassic for webOS 之后发现，既然 webOS 还能跑 JS，那为什么不顺便做个 DeepSeek 客户端呢？于是就有了这个新坑。目前只能简单对话的说……
